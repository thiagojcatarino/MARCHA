# Insumos locais da pesquisa

O código espera os seguintes arquivos em `data/`:

- `PauloGustavo - 6 - Painel de Utilização - Lista Município_Detalhamento Municípios_Tabela.csv` — detalhamento de utilização dos recursos da Lei Paulo Gustavo;
- `br_inep_ideb_municipio.csv` — indicadores municipais do IDEB;
- `highereduc.xlsx` — indicadores municipais de escolaridade.

A pasta enviada também contém outros arquivos e produtos de análise. Nenhum dataset foi copiado para o repositório nesta etapa. Antes de publicar os dados, confirmar fonte oficial, licença, tamanho, integridade, data de extração e se há restrição de redistribuição. Para reproduzir resultados já calculados, documentar separadamente os arquivos esperados em `output/`.
