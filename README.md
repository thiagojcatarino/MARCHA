# MARCHA

Protótipo institucional do Museu Virtual Multidisciplinar e arquivo público de pesquisa.

## Ver localmente

Abra `index.html` no navegador. O índice mantém registros de reserva locais e carrega `data/catalog.json` quando servido por HTTP.

## Estrutura

- `index.html` — página e conteúdo editorial.
- `assets/css/` — estilos globais, navegação e homepage.
- `assets/js/` — menu e catálogo.
- `data/catalog.json` — catálogo inicial de pesquisa.

O projeto não usa framework nem etapa de compilação.
